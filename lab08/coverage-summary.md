# Покриття тестами Core: лабораторна 8

Вимірювання: .NET 10, xUnit, Coverlet (`XPlat Code Coverage`). Усі 25 тестових сценаріїв пройшли.

Покриття рядків Core: **28.93%** (193 із 667 виконуваних рядків).
Покриття розгалужень: **27.55%** (54 із 196).

Асинхронні методи та ітератор враховані разом зі згенерованими компілятором машинами станів у відповідному просторі імен. Покриття збирається лише для Core, оскільки тестовий проєкт не посилається на Cli.

Непокриті ділянки: попередні CSV/JSON-імпортери товарів, файлове сховище та кеш, фабрика, демонстраційні дані й інформація про середовище, бенчмарк і частина звітів та доменних переходів. Модульні тести лабораторної зосереджені на інваріантах, подіях, імпорті, прогресі й скасуванні; файлова інфраструктура потребує окремих інтеграційних тестів. Для демонстрації вимог цієї лабораторної часткове покриття прийнятне; цей показник не підтверджує повну перевірку всього Core.

Відтворення:

```sh
dotnet test --collect:"XPlat Code Coverage"
```

Collector створює `tests/Core.Tests/TestResults/<ідентифікатор>/coverage.cobertura.xml`. Ідентифікатор змінюється з кожним запуском. Файл XML залишається локальним результатом тестів; цей підсумок збережено у репозиторії.
